# Notes Management System

A RESTful backend application developed using **Java, Spring Boot, and SQL Server** to manage notes through CRUD operations.

## Features

* Create, read, update, and delete notes
* REST API development
* SQL Server database integration
* API testing using Postman

## Technologies

**Java | Spring Boot | REST APIs | SQL Server | Postman | Maven**

## Run the Project

```bash
mvn spring-boot:run
```

Configure your database credentials in `application.properties` before running the application.
